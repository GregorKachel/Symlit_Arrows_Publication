## Deixis in the Graphic Domain - Young Children's Comprehension of Arrows and Markers

------------------------------------------------------------------------

> Data and analysis scripts associated with the following paper

------------------------------------------------------------------------

Kachel, G., O'Madagain, C., Haun, D. & Bohn, M. (2025). [Deixis in the Graphic Domain - Young Children's Comprehension of Arrows and Markers](https://osf.io/preprints/psyarxiv). *PsyArXiv*, Month Day.

### Structure

```         
.
├── materials
    ├── S1_arrow&marker                 <-- Counterbalanced Presentations as used in study 1
    ├── S2_distance&direction           <-- Counterbalanced Presentations as used in study 2
    └── S3_unconventionalarrows         <-- Counterbalanced Presentations as used in study 3
├── manuscript                          <-- Computationally Reproducible Manuscript Folder 
    ├── symlit_arrows_analyses.r        <-- Main Analysis Script
    ├── symlit_arrows_manuscript.Rmd    <-- For knitting main document
    ├── symlit_arrows_supplement.Rmd    <-- For knitting supplement
    ├── library.bib                     <-- bibtex four references
    └── apa7.csl                        <-- for knitting APA7 style manuscripts
├── data                            <-- raw data as basis for the analyses
├── results                         <-- output of analysis script as csv and rds
├── illustrations_raw               <-- parts of illustrations to be sourced
├── illustrations                   <-- output of analysis script for creating illustrations
├── preregistration                 <-- PDF Preregistrations for all studies as available on aspredicted.com
└── models                          <-- saved model outputs for all analyses
```
